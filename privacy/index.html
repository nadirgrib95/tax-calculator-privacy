Local storage and optional cloud sync / Stockage local et cloud facultatif

WorkSlip works offline and saves records on your device. When you enable private-code sync, we use Supabase in Canada (ca-central-1) to store a workspace identifier, a hash of its private code, your business profile and logo, clients and their contact details, products, invoices and amounts, scheduled work, notes and completed time sessions. This supports backups across devices and future desktop access. Running timers and unfinished form drafts remain on the device. Network providers may process connection and security logs, including IP addresses.

WorkSlip fonctionne hors ligne et enregistre sur votre appareil. Avec la synchronisation par code privé, Supabase conserve au Canada un identifiant d’espace, l’empreinte du code, votre profil et logo, coordonnées clients, produits, factures et montants, travaux, notes et sessions terminées pour l’accès sur plusieurs appareils. Les chronomètres actifs et brouillons restent locaux. Les fournisseurs peuvent traiter des journaux de connexion et sécurité, dont l’adresse IP.

Purpose and security / Finalité et sécurité

We use business records to provide synchronization and app functions. No email/password or Clerk account is implemented. A private 256-bit code grants access to its workspace; anyone with that code can read, edit or delete those records. Keep it private. The database stores only a hash of the code. Transfers use HTTPS. Salted IP/day hash buckets limit workspace creation. Direct public access to database tables is blocked. Local storage relies on operating-system protections and is not separately encrypted by WorkSlip. Protect your device and credentials. WorkSlip includes no advertising, advertising identifiers or behavioural analytics and does not sell your records. Supabase is a service provider; see its privacy policy. GitHub Pages hosts this website and may process access logs under GitHub’s policy.

Les données servent à l’authentification, synchronisation et fonctions de l’application. Un code privé permet l’accès à son espace. Toute personne avec ce code peut lire, modifier ou supprimer ces données; gardez-le privé. Le serveur conserve seulement l’empreinte du code, sans compte ni connexion courriel. Les transferts utilisent HTTPS. Le stockage local dépend des protections du système sans chiffrement supplémentaire par WorkSlip. Protégez l’appareil et vos identifiants. Aucune publicité ni analyse comportementale; aucune vente de vos données.

Retention and deletion / Conservation et suppression

Records remain locally until you remove them or uninstall. Cloud records remain until you delete them with sync enabled or delete the workspace. In Settings → Sync & backup → Manage private connection → Delete cloud data, you can permanently delete that workspace and its cloud records, along with this device’s cache and private drafts. Replace private code revokes the old code and requires other devices to use the new code. Export anything you need first. Offline record deletions are queued until reconnection. Deleted-record markers may remain to synchronize deletions, without the removed record content. Uninstalling does not delete cloud records. Other devices, backups and shared copies must be removed separately. Cloud deletion does not cancel store subscriptions. Purchase providers may retain transaction and fraud-prevention records as legally required.

To delete cloud records without the app, use the private-code form below. It sends the code directly to your Supabase workspace endpoint over HTTPS; this website does not save it. Do not email your private code to support. For privacy or support help, contact nadirgrib95@gmail.com without passwords or unnecessary client records. We verify requests using only reasonably necessary information. Lost private codes cannot be recovered through email login in this release. Exported backups do not include the code; save it separately and privately.

Les données cloud restent jusqu’à suppression synchronisée ou suppression de l’espace. Réglages → Synchronisation et sauvegarde → Gérer la connexion privée → Supprimer les données cloud efface cet espace, son code et le cache sur cet appareil. Remplacer le code révoque l’ancien. Les suppressions hors ligne attendent la connexion. Désinstaller ne supprime pas le cloud et ne résilie pas l’abonnement. Supprimez séparément sauvegardes et copies partagées. Sans l’application, utilisez le formulaire ci-dessous : le code est envoyé directement à Supabase en HTTPS sans être enregistré sur ce site. N’envoyez jamais votre code privé par courriel. Contactez nadirgrib95@gmail.com pour l’aide. Aucun compte ni récupération du code par courriel n’est disponible; conservez le code séparément des sauvegardes.
